--- Step 5: public signup ----------------------------------------------------
[x] 5.1  Add public POST /signup (no bearer, rate-limited like /login) that
         creates a BRONZE member with no parent, via a new atomic
         db.create_signup_member() (mirrors accept_invite_atomic's
         collision-checked insert), stamping current TOS_VERSION.
         Note: adjusted scope during build — invites in this system are
         pre-addressed to a specific invitee_email at creation time, so
         "your own invite code" to hand out like a coupon doesn't fit the
         data model. /signup instead returns role="contributor" (the
         exact role POST /invites already authorizes to create invites),
         so a new member can immediately call POST /invites themselves.
         Throttled per-IP (SIGNUP_MAX_PER_IP=5/SIGNUP_WINDOW_SECONDS=1h,
         counts successes only) rather than reusing RATE_LIMIT_PER_MIN,
         which is sized for the streaming-poll path and usually off.
         verify: SignupTests in tests/test_coordinator_e2e.py — token
         resolves to the right member, contributor role satisfies the
         /invites authorization check, ToS required, duplicate
         username/email 409, throttle blocks after N successful
         signups from one IP and does NOT count failed attempts. Full
         suite: 570/570 green. (2026-08-19)
