PWA REFACTOR + ARCHITECTURE CLEANUP — CHECKLIST
================================================

Goal: turn the Flask web UI into an installable PWA with offline shell
and (eventually) push notifications, without losing logic during the
modularization work. PWA reference: PWA_REFERENCE.md (React/Vite stack —
patterns transfer; we re-implement in Flask + vanilla ES modules +
pywebpush instead of vite-plugin-pwa + web-push).

Ground rule for every "move" task below: cut-and-paste the existing
code verbatim. Only mechanical changes (import/export, qualify `me` as
`state.me`, etc.) are allowed. No improvements, no renames, no
"while we're here" tweaks. Behavior must be identical post-refactor.


PHASE 0 — Decisions (one-time, recorded here so we can refer back)
==================================================================

  - Module system: ES modules (`<script type="module">`). Each split
    file is `client/static/js/<name>.js`, uses `import { ... } from
    './<other>.js'`. Reasons: explicit deps, strict mode default,
    no global namespace pollution, modern-browser native.
  - Shared mutable state: one `state.js` module exporting an object
    (`export const state = {...}`). Other modules mutate via
    `state.foo = bar`. This is the minimum syntactic change required
    to share `let`-scoped variables across modules.
  - SW strategy: hand-rolled `sw.js` (no Workbox/vite-plugin-pwa
    dependency — we have no build step). One file, one install
    handler, one fetch handler, one push handler.
  - Push backend: pywebpush on the coordinator (it owns the DB and
    member auth). Client/Flask just proxies subscribe/unsubscribe.
  - Icon strategy: generate from a single source SVG/PNG at the sizes
    required by manifest + apple-touch-icon. Placeholders OK initially
    so we can finalize art later (PWA_REFERENCE.md §8 warns iOS caches
    icons stickily — bump filenames when redesigning).

NOTES
=====
- Every Phase 1 file move must preserve every comment verbatim. The
  comments encode design decisions and incident history; losing them
  is a regression.
- For circular imports between streamingEngine ↔ messageRenderer:
  ES module live bindings handle this fine because the cross-module
  function references are used only inside function bodies (not at
  module-evaluation time). If we hit a real cycle issue, the escape
  hatch is to move makeRetryButton's caller (messageEl) to call
  retry via a late-bound reference set up in chat.js init.
- Keep the existing static-file paths (/static/js/...) — the SW
  precache list in Phase 4 will need to list them explicitly.
- We may need to add a Flask handler to serve sw.js with the right
  Content-Type and Service-Worker-Allowed scope; Flask's default
  static handler should work but worth checking in Phase 4.
- DO NOT touch coordinator, worker, or agent code during Phases 1-5.
  Push notifications (Phase 6) is the first time the backend is
  modified for this initiative.
